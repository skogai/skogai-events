# CLAUDE.md

Claude Code plugin `skogai-events`: one script per hook event, each logging a JSON row. It was `plugins/skogai-core` in skogai2/marketplace until 0.11.1; that copy stays there for its current users and is not developed further. The marketplace lists this repo as an external plugin. Where it is heading: workorder 0001 in skogai2/marketplace (`.skogai/workorders/0001-skogai-events.md`).

- @FEATURES.md
- `hooks/hooks.json` is generated by `scripts/generate-hooks-json.sh` from `scripts/events/*.sh`; never hand-edit it. `--check` fails on drift, and CI and `tests/run.sh` run it.
- Every script sources `scripts/guard.sh` first: with `enabled` off (the default) the hook ends there. A hook must never exit 2 by accident, since that blocks the event.
- Settings are mod settings (`userConfig` in `.claude-plugin/plugin.json`), read from `CLAUDE_PLUGIN_OPTION_<KEY>` by `scripts/settings.sh` and from `options` by `hooks/register.ts`.
- Read `LEARNINGS.md` before touching `hooks/register.ts`.
- The hook reference is `docs/hooks.md` in skogai2/marketplace.

## Checking a change

- `tests/run.sh`: the scripts, in a throwaway git repo. Needs `bash`, `jq`, `git`, `flock`.
- `claude plugin validate .`
- `claude -p "reply with just OK" --plugin-dir .`: headless load check.
